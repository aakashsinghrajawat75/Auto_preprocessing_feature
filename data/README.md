# 📁 `data` — Built-in Sample Datasets

The `data` directory contains built-in messy, multi-format sample datasets used for demonstration and testing.

---

##  File Inventory

| Dataset File | Format | Description & Test Purpose |
| :--- | :--- | :--- |
| **`housing_sample.csv`** | CSV | Real Estate dataset containing messy unit strings (`"1,450 sq.ft."`, `"3 BHK"`, `"85 Lakhs"`) and missing cells. |
| **`products_sample.json`** | JSON | E-Commerce nested JSON containing product IDs, names, prices, ratings, and stock statuses. |
| **`logs_sample.xml`** | XML | System log tree containing log attributes, timestamps, retry counts, and response times in milliseconds. |
